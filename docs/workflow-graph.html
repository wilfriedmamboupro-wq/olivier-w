Lanebook Workflow Graph

The RFP pipeline as a node graph, with its decision points: a lane that can't be fully routed, a cancelled approval, and the choice between a simulated or a real customer reply.

Claude (AI) Human System (deterministic) Mixed

Design principle: Claude never touches the numbers that matter — routes and prices are always computed by deterministic code first, and Claude only drafts the prose around them. Every action with a real external effect (sending an email) passes through an explicit human approval.
